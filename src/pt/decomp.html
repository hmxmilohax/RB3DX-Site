Descompilação do Rock Band 3

O que é isso?

É um projeto de engenharia reversa com o objetivo de produzir uma descompilação funcionalmente equivalente da versão de Wii do Rock Band 3. Esse processo envolve escrever código em C++ que produz um código similar a versão final do jogo.

A versão final disso tudo será uma versão totalmente editável do código do jogo em C++ legível por humanos. Isso irá permitir modificações além do que já podem ser feitos no Rock Band 3 Deluxe.

Por que a versão de Wii?

É bem simplesmente, essa é a única versão do jogo que é viável produzir uma descompilação precisa. Outras versões passariam por um processo chamado Link-Time Optimization que faz o código mais rápido, porém para nós isso é uma enorme desvantagem, tornando completamente inviável um projeto de descompilação preciso.

Como posso contribuir?

Você pode contribuir aqui. Nós sempre iremos procurar por mais contribuidores para seguir em frente com o projeto.

E sobre port?

Para começar, ressaltamos que projetos de descompilação NÃO tem como objetivo ports. Dito isso, este é um caso muito raro em que as pessoas que trabalham nesse projeto de descompilação também estão interessadas em portar a base do código para mais plataformas.

Mantenha em mente que esse processo é extremamente demorado, e nós não iremos fazer nenhuma tentativa de port até o jogo ser completamente descompilado. Se você realmente quer fazer o port ser feito mais rápido e você tem conhecimento técnico (ou tem interesse em aprender), você devia considerar ajudar no projeto.

Vocês serão ser capazes de [modificar] com isso?

Teoricamente sim, mas tamanha modificações estão totalmente fora do escopo desse projeto. Esse projeto se preocupa apenas em produzir um código C++ legível que pode ser usada para criar tais modificações.
